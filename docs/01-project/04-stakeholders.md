
# Stakeholders

## 1. Propósito

Identificar las personas y grupos que participan en los procesos de Fresitas y que interactuarán directa o indirectamente con el sistema híbrido Etherware™, definiendo su nivel de acceso y relación con la plataforma.

## 2. Stakeholders identificados

| Stakeholder                        | Relación con el negocio o sistema híbrido                                                                                              |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **Gerencia / Administrador** | Tiene acceso total al Portal Privado. Analiza el Dashboard estadístico, exporta reportes en PDF y gestiona inventarios y usuarios.      |
| **Vendedores**               | Operan el Portal Privado. Reciben los pedidos generados en la web, validan pagos por WhatsApp, gestionan leads y actualizan estados.     |
| **Clientes (Finales)**       | Operan el Portal Público. Navegan el catálogo interactivo, arman su carrito de compras y envían el pedido estructurado vía WhatsApp. |
| Personal de inventario / almacén  | Participa en el registro físico de productos. El sistema les notifica (o consultan) las alertas de bajo stock y salidas validadas.      |
| Despachadores / Domiciliarios      | Ejecutan las entregas. Su gestión depende de los estados de pedido actualizados por los vendedores en el sistema.                       |
| Productores / Fábrica             | Proveen los productos. Sus entregas alimentan el módulo de ingresos de inventario del administrador.                                    |
| Contabilidad                       | Se apoya en los reportes exportables (PDF) y las estadísticas del Dashboard para el control financiero de las ventas cerradas.          |
| Proveedores                        | Abastecen materias primas. Su gestión se apoya indirectamente en las alertas de bajo stock generadas por el administrador.              |
