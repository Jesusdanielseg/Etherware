# Stakeholders

## 1. Propósito

Identificar las personas y grupos que participan en los procesos de Fresitas o que pueden interactuar con Etherware, así como su relación inicial con el sistema.

## 2. Stakeholders identificados

| Stakeholder                       | Relación con el negocio o sistema                                                            |
| --------------------------------- | --------------------------------------------------------------------------------------------- |
| Gerencia                          | Interesada en la visión general del negocio y en la información para la toma de decisiones. |
| Administrador del sistema         | Administra usuarios y, según los permisos definidos, funciones del sistema.                  |
| Personal de inventario / almacén | Participa en el registro y control de productos y existencias.                                |
| Vendedores                        | Participan en la gestión comercial y el registro de clientes potenciales.                    |
| Clientes                          | Originan solicitudes o pedidos y reciben los productos o servicios de Fresitas.               |
| Productores / fábrica            | Participan en los procesos de producción y disponibilidad de productos.                      |
| Despachadores                     | Intervienen en la preparación y coordinación de los despachos.                              |
| Domiciliarios / repartidores      | Ejecutan las entregas y actualizan su estado.                                                 |
| Contabilidad                      | Participa en los procesos contables y en la información asociada a las operaciones.          |
| Proveedores                       | Se relacionan con el abastecimiento y la gestión de compras.                                 |
