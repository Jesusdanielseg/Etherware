## 2. Responsabilidades del equipo

Al ser un desarrollo individual, las responsabilidades integrales comprenden:

- Analizar las necesidades operativas de Fresitas y estructurar el modelo híbrido (Web + WhatsApp).
- Mantener los requisitos y el Product Backlog actualizados.
- Diseñar la arquitectura del sistema (Portal Público y Privado), base de datos e interfaces.
- Desarrollar e integrar las funcionalidades de Frontend y Backend (incluyendo Dashboards y PDFs).
- Realizar pruebas de integración local y corregir defectos.
- Mantener la documentación técnica y de usuario alineada con el código real.
- Gestionar el control de versiones y los cambios de arquitectura mediante Git y GitHub.
- Garantizar la seguridad, el manejo estricto de roles y evitar la exposición de datos sensibles.

## 4. Acuerdos de trabajo

- Dividir el trabajo en incrementos modulares pequeños, verificables y funcionales.
- Mantener el tablero de seguimiento y los artefactos Scrum actualizados en cada sesión de desarrollo.
- Documentar las decisiones técnicas críticas y los cambios de arquitectura.
- Revisar y auditar el código localmente antes de realizar *commits* e integraciones a la rama `main`.
- Criterio de "Terminado" (DoD): Una tarea no se considera completa por el simple hecho de escribir el código; debe pasar las pruebas locales, cumplir el diseño visual aprobado y estar respaldada en el repositorio.
